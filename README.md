# NasChat App

Welcome to NasChat — a modern, AI-powered social platform built for real conversations.

## Getting Started

### Web Development

```bash
pnpm install
pnpm web
```

The web app will start at [http://localhost:5000](http://localhost:5000)

## Development Resources

NasChat is built with [React Native](https://reactnative.dev/) and TypeScript, powered by the AT Protocol for decentralized social networking.

## Build Instructions

See [./docs/build.md](./docs/build.md) for full build instructions.

## Platform

- **Frontend**: React Native Web (Expo)
- **Backend**: AT Protocol / AppView
- **Mobile**: iOS & Android (Expo)
- **Future Production Domain**: naschatai.com
